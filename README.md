# Plato's Pizza — Analyse de l'activité

Projet Data Analyst (SQL · Python · Streamlit) autour des données de ventes de Plato's Pizza.

## Contenu du dépôt

- `data/` — fichiers CSV sources (orders, order_details, pizzas, pizza_types)
- `create_db.py` — script de création de la base SQLite `pizza.db` à partir des CSV
- `analysis.ipynb` — requêtes SQL d'analyse et interprétations
- `app.py` — application Streamlit
- `pizza.db` — base de données générée (non versionnée si trop volumineuse)
